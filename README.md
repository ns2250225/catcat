# 流浪猫小院 Stray Cat Yard

2D 像素 · 模拟经营 · 放置收集 · 猫咪图鉴。纯前端单机游戏（Web / PWA），无需登录，存档保存在浏览器本地。

> 给那些没有家的猫，准备一个它们愿意回来的地方。

## 运行

```bash
npm install
npm run dev       # 开发模式  http://localhost:5173
npm run build     # 类型检查 + 生产构建，输出到 dist/
npm run preview   # 预览生产构建（含 PWA 离线缓存）
```

## 技术栈

Vue 3 + TypeScript + PixiJS 8 + Pinia + IndexedDB + Web Audio API（无后端，无任何图片 / 音频素材：所有像素画与声音都是程序实时生成的）。

## 内容一览

| 系统 | 内容 |
|---|---|
| 猫咪 | 120 只固定图鉴猫（含 20 只条件稀有猫）+ 约 120 万种随机流浪猫外观组合 |
| 设施 | 106 种（食物 / 饮水 / 休息 / 娱乐 / 卫生 / 遮蔽 / 植物 / 装饰 / 地面），支持拖动、旋转、换皮肤、收回仓库 |
| 礼物 | 60 种材料（普通→珍贵 4 档）+ 120 件猫咪专属宝物，可“旧物改造” |
| 对话 | 3000+ 条情境台词 + “开头 + 事件 + 性格结尾”组合生成；双猫对话、事件台词 |
| 事件 | 57 种动态事件（偷鱼、抢纸箱、送礼、猫咪大会……） |
| 成就 | 167 个（含 15 个隐藏成就） |
| 世界 | 7 个时段昼夜循环、10 种天气（影响猫咪行为）、四季（可同步现实日期）、节日、月相 |
| 其他 | 小院 5 级扩建、温暖度 8 项属性、熟悉度 6 级、猫咪关系网络、来访记录、离线模拟（最多 12 小时）、导入 / 导出存档、动态 BGM 与环境音 |

## 目录

```
src/
  data/          静态数据：cats / buildings / items / dialogue / achievements
  game/
    core/        Game 主循环、随机数、事件总线
    world/       时钟、天气、小院几何与温暖度
    cats/        猫咪实体与 AI 状态机、来访算法、随机猫生成、对话选择
    gifts/       礼物掉落
    events/      动态事件脚本
    audio/       Web Audio 合成音效 / 环境音 / BGM
    render/      PixiJS 渲染器、像素画（猫咪 / 设施 / 场景）
    save/        IndexedDB 存档、导入导出
  stores/        Pinia UI 状态
  components/    界面组件
```

## 玩法提示

- 点击猫碗倒猫粮、点击水碗加水、点击猫砂盆清理；顶部「🧺 照料」可一键完成。
- 点击地上的 🎁 打开礼物；点击猫咪查看信息卡并“摸摸”。
- 猫咪带来的小东西就是建造材料；在「🔨 建造」中制作设施并扩建小院。
- 温暖度越高，来的猫越多、停留越久，稀有猫和稀有礼物越容易出现。
- 有些猫只在特定的时间、天气、季节或条件下才会出现——留意图鉴里的线索。
